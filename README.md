# כרטיס ביקור דיגיטלי

אפליקציית MVP בעברית ליצירת כרטיס ביקור דיגיטלי עם תצוגה מקדימה חיה.

## הרצה

```bash
npm install
npm run dev
```

לאחר מכן פותחים את הכתובת שמודפסת בטרמינל (ברירת המחדל היא `http://localhost:5173`).

## בדיקות

```bash
npm test
```

המידע נשמר בדפדפן בלבד (`localStorage`); אין שרת, חשבונות משתמשים או מסד נתונים.
