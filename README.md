# כרטיס ביקור דיגיטלי

אפליקציית MVP בעברית ליצירת כרטיס ביקור דיגיטלי עם תצוגה מקדימה חיה.

## הרצה

```bash
npm install
npm run dev
```

לאחר מכן פותחים את הכתובת שמודפסת בטרמינל (ברירת המחדל היא `http://localhost:5173`).

## בנייה לפריסה

הפרויקט משתמש ב-Vite. כדי ליצור גרסת production בתיקיית `dist` ולהציג אותה מקומית:

```bash
npm run build
npm run preview
```

ב-Vercel יש להשתמש בפקודת הבנייה `npm run build` ובתיקיית הפלט `dist` (זיהוי Vite האוטומטי משתמש בהגדרות האלה כברירת מחדל).

## בדיקות

```bash
npm test
```

המידע נשמר בדפדפן בלבד (`localStorage`); אין שרת, חשבונות משתמשים או מסד נתונים.
